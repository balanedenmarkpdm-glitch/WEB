# Balane Act Deploy

This portfolio and project showcase contains the complete deployment-ready website and all seven activity projects.

## Structure

- `index.html` — portfolio homepage
- `assets/` — shared portfolio styles, scripts, and images
- `projects/` — seven activity websites grouped by activity number and term

## Preview locally

From the project root, run a static server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in a browser.

## Deployment

This folder is ready to be pushed to GitHub and deployed through Vercel as a static site.
